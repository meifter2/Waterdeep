# DFY · El sonido de tus aventuras

Mesa de sonido personal para dirigir partidas de Dungeons & Dragons: la música y los sonidos de tus personajes,
lugares, ambientes y efectos, listos para sonar con un toque (Spotify, YouTube y archivos propios).

**DFY**: la D es el dado D20; FY, un guiño a Spotify. Antes se llamaba «Banda sonora».
No incluye contenido de ningún libro: cada máster añade el suyo.

## Probarla en local

```bash
npm install
npm run dev
```

Sin variables de Supabase funciona en «modo local» (todo en el navegador). Configuración de Supabase y variables:
ver `bd/LEEME.md`. Guía técnica para el desarrollo: `CLAUDE.md`.
