# Mesa del Máster

Aplicación para facilitar el trabajo del máster en «Waterdeep: Dragon Heist» y mejorar la experiencia de los jugadores.
No incluye contenido del libro: cada máster introduce el suyo.

## Probarla en local

```bash
npm install
npm run dev
```

Abre la dirección que aparece (normalmente http://localhost:5173) y pulsa «Cargar una campaña de ejemplo».
